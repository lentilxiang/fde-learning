原始课程：<https://cloud.tencent.com/edu/learning/course-4742-84527-84531>

## 这是什么

不是课程链接的收藏夹，而是把课程**完整抓取到本地**的离线版本——课程正文原本由 JS 动态加载、资源托管在私有 COS 桶，直接打开页面什么都拿不到。这里包含：

- 4 章 19 节全文，**126,691 字**
- **265 张配图**（121MB）+ Claw 演示视频，全部本地化
- 第 3 章实战所需的 **5 个教学素材**（4 docx + 1 xlsx）
- 一套可执行的 **16 天学习路线**

打开 `index.html` 即可阅读，**零网络依赖**，断网可用。

## 学习路线要点

每天 2 小时，16 天 = 32 小时，分四个阶段：

1. **概念地基**（D1–D2）— AI/LLM/Agent 的因果链，三种编排方式
2. **产品能力**（D3–D5）— ADP 五件套、知识库与 RAG、能力地图
3. **动手开发**（D6–D11）— 方案设计 + 5 个实战，**全程上机**
4. **调优交付**（D12–D16）— 评测集、Prompt 调优、RAG 调优、终局项目

详细到每天读什么、做什么、怎么验收，见 [`学习路线.md`](./学习路线.md)。

## 技术说明

课程页面有三个坑，抓取脚本 `tools/` 里都处理了：

1. **静态 HTML 无正文** — 正文由 `POST /edu/learning/api/newCourse/getHtmlChapterDownloadUrl` 按章分发，返回带 `q-signature` 的临时签名 URL（短时效，必须当场取当场下）。
2. **COS 私有桶 403** — `cert-private-*` 桶不带签名一律 AccessDenied；图片视频在另一个公开桶 `academy-pub-*`，可直连。静态 curl 打接口会被风控（返回混淆 JS），必须在浏览器页面上下文里 fetch。
3. **CSS 作用域是 `.html-course-theme`** — 只截"含课程类名"的规则会因丢失选择器前缀而全部失效，取到的全是浏览器默认样式。DOM 层级也必须复刻原站 `.layout` 的 grid（`300px 1fr`），否则图片渲染宽度会偏小。

复现命令见 `tools/`。
